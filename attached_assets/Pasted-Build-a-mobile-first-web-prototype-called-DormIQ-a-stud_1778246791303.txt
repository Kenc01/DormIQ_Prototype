Build a mobile-first web prototype called DormIQ — a student-verified boarding house discovery platform for Filipino college students. This is a pitch demo prototype, not a real backend app. Use React with Tailwind CSS. All data is hardcoded/mock. No login system needed. No real database.

=== APP STRUCTURE ===
Single-page app with 5 screens. Use a bottom navigation bar with icons to switch between screens. Screens:
1. Home (search/map view)
2. Results (dorm list)
3. Dorm Detail (listing page)
4. Review (submit a review)
5. Landlord (register a dorm)

The bottom nav should always be visible. Highlight the active screen tab in teal (#028090).
